Privacy Policy

Last updated: September 17, 2026

Overview

RoodNick Channel Digest is a personal-use application developed and operated by RoodNick. It helps an authorized user organize YouTube subscriptions and receive a categorized digest of newly published videos.

Google user data accessed

The application uses the read-only YouTube OAuth scope. It may access the authorized user's YouTube subscription list and public metadata associated with subscribed channels and their videos, including channel names, descriptions, identifiers, thumbnails, video titles, publication dates, and links.

How data is used

The data is used only to synchronize the user's subscriptions, categorize channels, identify new videos, prevent duplicate digest entries, and create the user's requested Telegram digest. The application does not use Google user data for advertising, profiling, or unrelated purposes.

Storage and security

OAuth credentials, subscription information, categories, and digest history are stored locally in files and a private database controlled by the authorized user. Credentials are excluded from public source control and are restricted to the local account where the application runs.

Sharing and disclosure

Google user data is not sold, rented, or shared with third parties. Selected video metadata may be sent to the user's own Telegram chat solely to deliver the requested digest.

Retention and deletion

Data is retained only while the application is in use. The user can delete the local database and OAuth token files at any time. Access can also be revoked from the Google Account's third-party access settings.

Limited use

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
